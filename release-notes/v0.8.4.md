# v0.8.4 — 细节打磨

> 本次是 0.8.3 之后的小幅优化，专注交互细节。

---

## ✨ 改动

### 卡片悬停更精致 · 0.8.4
窗口 / 提示词 / 技能 / MCP 四个列表的卡片：
- 平时是**直角**（和列表融为一体）
- 鼠标**悬停时平滑过渡为圆角** + 浅底色

### 新建窗口更干净 · 0.8.4
新建窗口时（还没选平台），会**隐藏侧边栏、项目选择器、地址栏**，让平台选择页铺满整个窗口。
选完平台后，一切恢复正常。

---

## 📦 安装

- **Windows**：下载 `cuckoo-code-win-v0.8.4.exe`（安装版）或 portable 版。
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）。

> 已有 0.8.x 用户：启动后稍等会收到自动更新提示；也可到「关于 → 检查更新」。
