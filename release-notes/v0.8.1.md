# v0.8.1 — 技能快捷栏 + 自绘标题栏

> 本次让技能"看得见、点得动"：地址栏下方新增技能快捷栏，点一下就填好调用语；
> 窗口换成自绘仿 macOS 标题栏，并统一为浅色 Apple 风格。

---

## ✨ 新增

### 技能快捷按钮栏 · 0.8.1

地址栏下方新增一条技能栏，把所有**已启用**的技能列成小胶囊。点一下，就把
「使用「技能名」技能」这句话填进 AI 输入框——**只填不发**，你可以改完再发。

- 技能名自动去掉 .Skill(s) 后缀，短而好认。
- 若技能在 SKILL.md 里声明了 trigger / triggers，会带出第一个触发词，填得更完整。

### 自绘仿 macOS 标题栏 · 0.8.1

窗口改为**无边框 + 透明背景**，顶部自绘一条标题栏：

- 左侧红/黄/绿三个圆点：关闭 / 最小化 / 最大化（悬停显示图标）。
- 中间显示应用名与版本号，如 Cuckoo Code Pro v0.8.1。
- Win10 没有系统原生圆角，改用「透明窗口 + CSS 圆角」实现圆角外观。

### 技能中文显示名 · 0.8.1

从市场安装的技能，SKILL.md 里的 name 通常是英文。现在：

- 安装时自动记录市场提供的中文名（只采用含中文的名字，英文名不覆盖 SKILL.md 里的品牌名）。
- 技能面板新增「**更新名称**」按钮，一键从市场重新拉取已装技能的中文名；老技能没记录来源时，
  会用技能 id 去市场搜索匹配。

### 触发提示词（triggers）· 0.8.1

解析 SKILL.md frontmatter 里的 trigger / triggers 字段，支持 a, b, c 与 [a, b, c] 两种写法，
去重后供技能快捷栏使用。

## 🐛 修复

- **SKILL.md 带 BOM 解析失败** · 0.8.1：某些编辑器/工具写文件会加 UTF-8 BOM，
  会让开头的 --- 识别不到。现在解析前自动剥离 BOM。
- **老技能名反查** · 0.8.1：修复没有 slug/namespace 记录的技能无法反查中文名的问题。

---

## 🔧 改进

- **浅色主题** · 0.8.1：界面统一为 Apple 风格浅色（主色 #0071e3，工具栏 #f5f5f7）。
- **工具调用提示文案** · 0.8.1：遮罩文字改为「正在执行工具调用，请稍候…」。

## 📦 安装

- **Windows**：下载 cuckoo-code-win-v0.8.1.exe（安装版）或 portable 版。
- **macOS**：下载对应架构的 .dmg（Intel 选 x64，Apple Silicon 选 arm64）。

> 已有 0.8.0 用户：本版支持自动更新，启动后稍等即可收到提示；也可到「帮助 → 检查更新」。
